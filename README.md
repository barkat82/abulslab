# AbulsLab

AbulsLab is a professional architecture and research portfolio focused on agentic systems, trust engineering, platform engineering, quality engineering, and enterprise architecture.

## Site structure

- index.html — homepage
- pages/about.html — professional background and interests
- pages/initiatives.html — current initiative overview
- pages/research.html — research journal structure
- pages/patterns.html — reusable architecture patterns
- pages/writing.html — articles and thought pieces
- pages/projects.html — repository showcase
- pages/contact.html — contact page
- assets/css/site.css — visual system and layout
- assets/js/site.js — lightweight navigation enhancement

## Deployment

This site is designed for GitHub Pages and can be published directly from the repository root.
