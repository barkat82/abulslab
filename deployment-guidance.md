# GitHub Pages Deployment Guidance

## Recommended setup
1. Create or use a repository named abulslab.github.io.
2. Commit the site files to the repository root.
3. In GitHub repository settings, enable GitHub Pages using the root branch or docs folder.
4. Confirm the site is available at https://abulslab.github.io/.

## Maintenance guidance
- Keep the structure static and simple.
- Add new pages as standalone HTML files or migrate to a static-site generator later.
- Prefer Markdown-backed content for future expansion.
