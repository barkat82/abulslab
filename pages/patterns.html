Architecture Patterns

Reusable architectural ideas for intelligent systems.

These patterns reflect an architecture-first approach to agentic systems, trust, validation, and governance.

Agent Contract Pattern

Defines the boundary between an agent and the rest of the system through explicit contracts, expected behavior, and validation expectations.

Evidence Package Pattern

Captures the evidence needed to justify an action, decision, or assessment in a structured and auditable way.

Trust Assessment Pattern

Establishes a repeatable structure for evaluating an agent’s trust posture across domains such as reasoning, execution, visibility, and governance.

Validation Pattern

Separates the agent’s generation role from the system’s responsibility to validate outcomes before execution.

Governance Gate Pattern

Introduces controls that require human review, policy checks, or approval steps before high-impact actions proceed.
